Guidelines

Before giving access

  • Only share the private verification code with trusted staff.
  • Save Role applies role/status changes. Disable User blocks login and tracker data access.
  • Disable users immediately when they no longer need tracker access.
  • Use Reset Pass when a user forgets their password, then give them the new password privately.
  • Review history often for failed logins, registrations, and tracker saves.
  • Use admin roles only for people who should manage other users.
